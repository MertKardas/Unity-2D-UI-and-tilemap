# Unity 2D UI & Tilemap Project

This project focuses on 2D tile-based game development and user interface (UI) systems in Unity.  
It includes animation, interaction mechanics, audio design, and top-down movement systems.

---

## 📦 Third-Party Assets (Free)

- **LeanTween** – Tween-based animation system  
- **NaughtyAttributes** – Inspector enhancement toolkit  
- **2D Pixel Dungeon Asset Pack**  
  - Source: https://pixel-poem.itch.io/dungeon-assetpuck  

---

## 🧩 Unity Technologies Used

- **Cinemachine** – Advanced camera control  
- **Input System** – Modern input handling  
- **Tilemap** – 2D grid and tile system  

---

- **Singleton Pattern**

## 🎮 Game Features

- Top-Down Character Movement
